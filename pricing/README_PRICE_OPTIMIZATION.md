# Оптимизация Цены для Максимизации Маргинальности

## Описание

Этот скрипт определяет оптимальную цену товара для максимизации маргинальной прибыли на основе исторических данных о продажах, ценах и себестоимости.

## Возможности

- **Построение модели спроса**: Анализ зависимости продаж от цены (эластичность спроса)
- **Оптимизация цены**: Нахождение оптимальной цены для максимизации прибыли
- **Визуализация**: Графики зависимости спроса, выручки и маржи от цены
- **Анализ чувствительности**: Исследование влияния изменения себестоимости на оптимальную цену
- **Гибкие модели**: Поддержка линейной, логарифмической и полиномиальной моделей спроса

## Входные данные

Скрипт принимает три массива данных за период наблюдения (например, по дням):

1. **sales** - объем продаж (количество единиц товара)
2. **prices** - цена товара
3. **costs** - себестоимость товара

## Формат CSV файла

CSV файл должен содержать следующие колонки:

```csv
date,sales,price,cost
2025-01-01,150,95.5,60.2
2025-01-02,145,98.0,61.0
2025-01-03,160,92.3,59.8
...
```

- **date** - дата (необязательно, используется только для справки)
- **sales** - объем продаж (количество единиц)
- **price** - цена товара в этот день
- **cost** - себестоимость товара в этот день

## Типы моделей спроса

### 1. Линейная модель (`model_type='linear'`)
```
Q = a - b*P
```
- Простая и интерпретируемая
- Подходит для большинства случаев
- Постоянное изменение спроса при изменении цены

### 2. Логарифмическая модель (`model_type='log'`)
```
log(Q) = a - b*log(P)
```
- Константная эластичность спроса
- Подходит для товаров с постоянной ценовой чувствительностью
- Учитывает нелинейные эффекты

### 3. Полиномиальная модель (`model_type='polynomial'`)
```
Q = a + b*P + c*P²
```
- Более гибкая модель
- Подходит для сложных зависимостей
- Может учитывать точки перегиба на кривой спроса

## Выходные данные

Скрипт выдает:

1. **Оптимальную цену** - рекомендуемая цена для максимизации маржи
2. **Ожидаемый объем продаж** - прогноз продаж при оптимальной цене
3. **Ожидаемая маржа** - прогноз прибыли при оптимальной цене
4. **Процент маржи** - относительная маржинальность
5. **Улучшение** - насколько можно увеличить прибыль по сравнению с текущей ситуацией

## Визуализация

Скрипт создает 4 графика:

1. **Кривая спроса** - зависимость продаж от цены
2. **Кривая оптимизации маржи** - зависимость прибыли от цены с отметкой оптимума
3. **Выручка vs Себестоимость** - анализ рентабельности
4. **Сводная статистика** - сравнение текущих и оптимальных показателей

## Анализ чувствительности

Функция `sensitivity_analysis()` показывает, как изменяется оптимальная цена при изменении себестоимости:

```python
# Анализ для диапазона себестоимости от 40 до 80
sensitivity_df = optimizer.sensitivity_analysis(cost_range=(40, 80), n_points=20)
```

Результат - DataFrame с колонками:
- `cost` - себестоимость
- `optimal_price` - оптимальная цена
- `optimal_margin` - оптимальная маржа
- `margin_pct` - процент маржи

## Ограничения и рекомендации

1. **Качество данных**: Чем больше исторических данных, тем точнее модель
2. **Вариация цен**: Данные должны содержать достаточную вариацию цен для построения надежной модели
3. **Внешние факторы**: Модель не учитывает сезонность, конкурентов, маркетинговые акции
4. **Проверка предположений**: Рекомендуется проверить R² score модели (>0.6 - хорошо)
5. **A/B тестирование**: Перед полным внедрением протестируйте новую цену на части аудитории

## Теоретическая основа

Скрипт использует следующие методы:

1. **Регрессионный анализ** - для построения функции спроса Q(P)
2. **Оптимизация** - для нахождения P*, максимизирующей функцию маржи:
   ```
   Margin(P) = Q(P) * (P - C)
   где Q(P) - функция спроса, C - себестоимость
   ```
3. **Численная оптимизация** - методы scipy.optimize для поиска оптимума
